# 자막 중복 정리

Anissia, Aniall, Naverblog 자막을 한 작업 공간에서 비교하는 Windows GUI 프로그램입니다.
입력 폴더·ZIP은 수정하지 않고 새 결과 폴더의 복사본만 정리합니다.

## 다운로드 및 실행

GitHub Actions의 **Build Windows EXE**가 성공하면 해당 실행의 `SubtitleCleaner-Windows` 아티팩트에서 ZIP을 다운로드하고 압축을 풀어 `SubtitleCleaner.exe`를 실행하세요. Python 설치 없이 실행할 수 있습니다.

1. 각 소스에 원본 폴더 또는 분할 ZIP 여러 개를 선택합니다. 독립 ZIP을 여러 개로 나눈 방식은 지원합니다. `.z01`/`.zip.001` 형태의 연속 분할 압축은 먼저 별도로 풀어 폴더를 선택하세요.
2. 결과 위치를 원본 폴더 밖에 지정하고 결과 위치를 확인합니다.
3. **전체 압축 해제·확장자 조사**를 누르면 선택한 소스 폴더 바로 아래의 폴더를 작품 단위로 보고, 각 작품 폴더의 ZIP과 중첩 ZIP을 재귀적으로 전부 해제합니다. ZIP 내부 폴더 계층은 벗기고 `expanded/소스/작품명/` 바로 아래에 파일을 모읍니다.
4. 같은 작품 폴더에서 같은 파일명이 충돌하면 덮어쓰지 않고 `__2`, `__3` 접미사를 붙여 모두 보존합니다. 결과는 `extension_inventory.csv`와 Excel의 **확장자조사** 시트에 기록되며, 이 1단계에서는 폰트·TXT·이미지 등도 그대로 조사합니다.
5. 조사 완료 후 **무확장자 형식 판별**을 누르면 확장자 없는 파일만 다시 읽어 자막·압축·일반 바이너리 형식을 식별합니다. 유효한 ZIP은 같은 작품 폴더에 바로 재귀 해제하고, 7z/RAR/EGG/ALZ/gz/bz2/xz/tar 등은 형식에 맞는 확장자를 붙여 보존합니다. 이미지·폰트·PDF도 대표 시그니처를 식별합니다. 전체 원본이나 이미 해제된 파일을 다시 스캔하지 않습니다.
6. **남은 압축파일 해제**는 설치된 Bandizip `bz.exe`를 자동으로 찾아 `.rar`, `.7z`, `.egg`, `.alz`를 검사·해제합니다. `폰트`/`font` 이름의 압축과 `.z01` 같은 분할 ZIP은 건드리지 않습니다. 해제된 파일은 같은 작품 폴더 바로 아래로 평탄화하고 이름 충돌은 `__2` 방식으로 보존하며, 새 파일을 manifest와 SHA 비교 대상에 추가합니다. 압축 안의 ZIP/RAR/7z/EGG/ALZ도 최대 8단계까지 이어서 처리합니다. 원래 압축파일은 유지합니다.
7. 그 뒤 **선택 확장자 적용·중복 정리**를 누르면 발견된 확장자 목록이 표시됩니다. 남길 자막 확장자를 직접 선택할 수 있으며 `.smi`, `.srt`, `.ass`, `.ssa`, `.vtt`, `.sub`, `.idx`는 기본 선택됩니다. `.txt`는 기본 선택하지 않습니다. 아직 풀지 못한 비폰트 압축 형식만 안전상 기본 선택됩니다.
8. 정리 실행 시 선택하지 않은 확장자는 `expanded/소스/작품명/` 해제본에서 제거하고, 선택된 파일은 **같은 소스의 같은 작품 폴더 안에서만** SHA-256이 같은 파일을 하나만 남깁니다. 같은 이름이지만 내용이 다르면 `__2`, `__3` 파일을 모두 보존합니다. 최종 ZIP은 다시 만들지 않습니다.
9. **원래 구조 복원**은 복구용 복사본에서 `restored/` 폴더를 만듭니다.

분할 ZIP만 있는 폴더(`anissia_subtitles_part001.zip` 등)를 선택하면 자동으로 내용물을 가져옵니다. 일반 자막 폴더 안의 ZIP은 자막 묶음으로 취급하며 폴더 구조를 그대로 유지합니다.

## 비교 기준

- 파일 SHA-256이 같으면 이름·소스·경로가 달라도 확정 중복입니다.
- 내부 ZIP까지 실제로 해제하고 개별 파일의 SHA-256을 비교합니다. 이름과 소스가 달라도 내용이 같으면 하나만 남깁니다. `1화 ZIP / 1~2화 ZIP / 1~3화 ZIP`도 회차별 동일 파일을 제거하고 고유한 파일은 남깁니다. 폰트·설명 파일도 개별 비교하며 내용이 다른 것은 보존합니다.
- 내용이 다른 번역자·릴·수정판은 자동 삭제하지 않습니다. 비슷한 이름이나 같은 작품·회차의 다른 내용은 검토 목록에 남깁니다.
- 제목은 정상 위치의 대표본 선택과 의심 후보 추출에만 사용합니다. 제목만으로 오배치를 확정하거나 삭제하지 않습니다.
- 대표본은 경로 작품명과 파일명·내부 자막명 일치 여부를 먼저 평가합니다. 동률이면 Anissia, Aniall, Naverblog 순서와 경로 순서로 결정합니다. 영문/한글 별칭을 이해하는 AI 매칭은 없으므로 대표 위치와 오배치 의심은 Excel에서 확인하세요.
- 소스 사이의 확정 중복 정리는 기본으로 켜져 있습니다. 끄면 각 소스 내부만 정리합니다.
- 빈 파일, 손상·암호화 ZIP, 검사 한도를 넘긴 ZIP은 자동 삭제하지 않습니다.
- ZIP 내부와 바깥의 일반 자막 파일도 함께 비교합니다. 일부 회차만 겹치는 ZIP도 중복 내부 파일을 제거해 다시 압축합니다. 남은 파일이 없는 ZIP은 제거하고 `ZIP재구성` 시트에 기록합니다. 비어 있던 원본 ZIP은 그대로 보존합니다.
- 싱크, 한 글자, 공백, 줄바꿈, 인코딩이 달라도 SHA-256은 달라지므로 자동 삭제하지 않습니다. 텍스트 정규화나 의미 유사도 기준 삭제는 하지 않습니다.

## 결과

`SubtitleCleanup_날짜시간/` 아래에 생성됩니다.

- `cleaned/anissia_subtitles/`, `cleaned/aniall_subtitles/`, `cleaned/naverblog_subtitles/`: 정리된 실제 폴더
- `anissia_subtitles_cleaned.zip`, `aniall_subtitles_cleaned.zip`, `naverblog_subtitles_cleaned.zip`
- `extension_inventory.csv`: 재귀 해제된 모든 파일의 확장자별 개수·용량·예시 경로
- `subtitle_cleanup_report.xlsx`: 요약, **확장자조사**, 삭제내역, 보존파일, 검토필요, 오배치, 공용첨부, 교차비교, ZIP재구성
- `manifest.json`: 재실행·복원을 위한 작업 기록
- `original_copy/`: 원래 상위 폴더·ZIP 복구용 복사본
- `expanded/소스/작품명/`: 각 작품 폴더의 ZIP을 모두 풀어 평탄화한 해제본. 확장자 선택·중복 정리를 실행하면 이 작업본이 그대로 최종 정리본이 됩니다.

Excel에는 필터·고정 헤더·숫자 크기 데이터가 포함됩니다. 공용 첨부와 교차 비교의 긴 경로 목록은 파일별 행으로 기록합니다. 파일 수·용량은 내부 ZIP까지 해제한 개별 파일 기준이며, 원래 상위 파일과 결과의 실제 용량도 요약에 별도로 기록합니다. 절약 용량은 최종 재구성 결과에서 제거된 파일의 비압축 바이트이며, 원본 보존 때문에 전체 디스크 사용량 감소를 뜻하지 않습니다.

1단계 조사는 원본·작업 파일을 삭제하지 않습니다. 내부 ZIP을 끝까지 해제한 뒤 모든 leaf 파일을 집계하고, 손상·암호화 ZIP 등 검증 불가 항목도 별도로 남깁니다. 2단계 정리는 사용자가 선택한 확장자만 남기며, 작품 폴더 내부의 동일 SHA만 제거합니다. 서로 다른 작품 폴더의 같은 파일은 합치지 않습니다. 중지하거나 실패하면 성공으로 표시하지 않습니다. 작업 기록을 불러와 원래 구조의 별도 복원본을 만들 수 있습니다.

## 한도 및 주의

검사 중 ZIP 내부 누적 해제량은 ZIP마다 2GiB, 재귀 깊이는 8단계입니다. 상위 입력 ZIP의 단일 파일도 2GiB로 제한합니다. 결과 폴더에는 복구용 복사본·해제 작업본·정리본·최종 ZIP이 생기므로 충분한 여유 공간이 필요합니다. 결과를 확인한 뒤 복원 기능이 필요 없으면 `original_copy/`와 `expanded/`를 직접 제거해 공간을 확보할 수 있습니다. 내부 ZIP은 실제로 해제하고 중복을 제거한 뒤 원래 경로·ZIP 계층으로 재압축합니다. 압축 시간·속성은 재생성되지만 남긴 파일 내용과 경로는 검증합니다. 비어 있던 원본 디렉터리는 파일 목록 기반 가져오기에서 재현하지 않습니다.

원본 변경이나 결과 파일 수동 편집이 감지되면 정리를 중단합니다. 결과 폴더를 통째로 옮긴 뒤 작업 기록을 불러올 수 있습니다. 원래 구조 복원에는 `original_copy/`가 필요합니다. 출처를 보존해야 한다면 소스 간 정리 옵션을 끄세요.

## 개발 및 직접 EXE 만들기

Python 3.12 이상의 표준 라이브러리만으로 프로그램이 동작합니다. Excel 작성도 외부 패키지가 필요 없습니다.

```powershell
python app.py
python -m unittest discover -s tests -v
```

Windows에서 `build_windows.bat`을 실행하면 테스트 후 `dist/SubtitleCleaner.exe`를 생성합니다. PyInstaller 설치에 인터넷 연결이 필요합니다.

자막·ZIP·작업 기록·결과물을 이 공개 저장소에 업로드하지 마세요. 프로그램은 로컬 파일만 처리하며 네트워크 업로드 기능이 없습니다.
